# Icon Validation Protocol

## Purpose

To determine whether the 13 semantic SVG icons are recognizable and meaningful to the target user population. Low recognition rates would invalidate the icon-anchored narration condition.

## Protocol

### Step 1: Setup (3 minutes)

1. Print icon cards (one icon per card, 8 cm × 8 cm, white background, black icon)
2. Prepare response sheet
3. Explain task: "I will show you pictures. Tell me what each picture means in your own words."

### Step 2: Free Association (20 minutes)

1. Present icons one at a time in random order
2. Show icon for 5 seconds
3. Ask: "What does this picture mean?"
4. Record exact verbal response
5. Do NOT provide hints or correct answers
6. If participant says "I don't know," move to next icon

### Step 3: Forced Choice (10 minutes)

1. After free association, present icons again
2. For each icon, show 4 options (1 correct + 3 plausible distractors)
3. Ask: "Which of these is the best meaning?"

**Example (Rain icon):**
- a) Rain / precipitation
- b) Water / irrigation
- c) Cloud / sky
- d) Season / monsoon

### Step 4: Contextual Validation (10 minutes)

1. Present 3 simple scenarios
2. Show relevant icon alongside scenario
3. Ask: "Does this picture match the story?"

**Scenarios:**
1. "It rained heavily yesterday." → Rain icon
2. "The temperature is very high today." → Temperature icon
3. "You should irrigate your crops." → Recommendation icon

## Scoring

### Free Association

| Score | Criteria |
|---|---|
| 1.0 | Exact match (e.g., "rain" for rain icon) |
| 0.5 | Semantic equivalent (e.g., "water falling" for rain icon) |
| 0.0 | Incorrect, unrelated, or "I don't know" |

### Forced Choice

| Score | Criteria |
|---|---|
| 1.0 | Correct option selected |
| 0.0 | Incorrect option selected |

### Contextual Validation

| Score | Criteria |
|---|---|
| 1.0 | Correctly matches icon to scenario |
| 0.0 | Incorrect match or "I don't know" |

## Success Criteria

| Criterion | Threshold | Action if Failed |
|---|---|---|
| Overall recognition rate | ≥ 70% (≥9/13 icons) | Redesign low-recognition icons |
| Critical icon recognition (rain, temperature, soil moisture, recommendation) | ≥ 90% | Mandatory redesign |
| Free association ≥ forced choice | No systematic bias | Check for leading in forced choice |
| No icon with 0% recognition | All icons recognized by ≥1 participant | Add more examples in testing |

---

## Decision Rules

| Scenario | Decision |
|---|---|
| ≥10/13 icons ≥ 70% recognition | Proceed with current icon set |
| 7–9/13 icons ≥ 70% recognition | Redesign 3–6 low-recognition icons; re-test |
| <7/13 icons ≥ 70% recognition | Full icon set redesign; delay pilot |
| Any critical icon < 70% | Redesign critical icon; re-test before pilot |

---

## Redesign Guidelines

If redesign is needed:
1. Replace abstract symbols with concrete pictorial representations
2. Test with 3 additional participants before re-testing full set
3. Consider culturally specific imagery (e.g., local crops, traditional tools)
4. Avoid text labels in icons (participants may read rather than recognize symbol)
5. Maintain visual consistency (line weight, color, style)
